# ล้างข้อมูลชุดใหม่ — เหลือเฉพาะใบ Pending (v5.1)

ใช้เมื่อต้องการเริ่มข้อมูลใหม่ โดยเก็บไว้เฉพาะใบเสนอราคาที่สถานะ **Pending** (ปล่อยราคาให้ Sales แล้ว รอลูกค้า)
ใบอื่นทั้งหมดถูกล้างออกจากระบบ ได้แก่ กำลังทำราคา · รออนุมัติ · อนุมัติแล้วรอปล่อย · Won · Closed · คำขอ (SR) ที่ยังไม่ได้ทำราคา · ใบที่ถูกลบ

> **ไฟล์อัปโหลดสร้างจากข้อมูลจริงในชีทของคุณ** — Claude ไม่มีสิทธิ์อ่าน Google Sheet ของบริษัท
> ระบบจึงมีเครื่องมือ 2 ตัวให้รันเองใน Apps Script: `exportPendingFile()` และ `importUploadFile()`

## สิ่งที่เก็บไว้
- ใบเสนอราคา Status = `Pending` ที่ไม่ถูกลบ: ทุกคอลัมน์เป็นค่าเดิม ทั้งราคาฉบับ Sales, ผู้ที่ได้รับราคา และประวัติ
- SR ต้นทางของใบเหล่านั้น เพราะเป็นหลักฐานคำขอของลูกค้า และใบเสนอราคาอ้างถึงอยู่
- ไม่แตะแท็บอื่น: Users · Products · MasterData · Sessions · Log · Settings (เพิ่มแค่ `dataEpoch`) · header ทุกแท็บเหมือนเดิม

## ขั้นตอน (Apps Script Editor → เลือกฟังก์ชัน → Run)
1. **วางไฟล์ v5.1 และ Deploy New version ก่อน** เพื่อให้ทุกเครื่องรู้จักสัญญาณ "ล้างข้อมูลชุดใหม่"
2. รัน `exportPendingFile()`
   - ได้ไฟล์ Google Sheet ชื่อ `MGS_Pending_Upload_<วันเวลา>` อยู่โฟลเดอร์เดียวกับชีทหลัก (URL อยู่ใน Execution log)
   - แท็บ **Quotations** = ใบที่จะเก็บ · แท็บ **อ่านก่อน** = จำนวนและสรุปสถานะทั้งระบบ
   - ขั้นนี้ยังไม่แตะข้อมูลในระบบ
3. เปิดไฟล์แล้วตรวจ ถ้ามีใบที่ไม่ต้องการ ให้ **ลบทั้งแถว** ได้ แต่ห้ามแก้ header, Id และ Detail
4. รัน `importUploadFile('<URL ของไฟล์>')` → อ่านรายงานใน Execution log
   - ต้องได้ `ok: true` และดูว่า `rowsInFile` กับ `willRemove` ถูกต้อง
   - ถ้ามี `problems` (เช่น มีสถานะอื่นปน, Detail เสีย, Id ซ้ำ, แก้ header) ระบบจะไม่ทำอะไร
5. รัน `importUploadFile('<URL ของไฟล์>', 'CLEAR_AND_IMPORT')` เพื่อทำจริง
   - สำรองทั้งไฟล์ก่อนอัตโนมัติ (`BACKUP yyyy-MM-dd HHmm — …`) ถ้าสำรองไม่สำเร็จจะยกเลิกทั้งหมด
   - ล้างแท็บ Quotations แล้วใส่แถวจากไฟล์ และล้างคิวแจ้งเตือน Lark เก่า
   - ตั้ง `dataEpoch` ใหม่ → ทุกเครื่อง (ระบบทำราคาและแอป Sales) จะล้างสำเนาในเครื่อง แล้วโหลดใหม่เองในรอบซิงค์ถัดไป (ภายใน 30 วินาที)
6. แจ้งทุกคนให้เปิดหน้าใหม่

## ความปลอดภัยของข้อมูล
- **สำรองสองชั้น**
  - ไฟล์ BACKUP ของทั้งชีทใน Drive
  - แต่ละเครื่องเก็บสำเนาเดิมไว้ใน localStorage คีย์ใหม่ `mgs_quotes_backup` (รวมรายการที่ยังค้างส่ง)
- **เครื่องที่ออฟไลน์หรือยังไม่อัปเดตส่งใบเก่ากลับขึ้นชีทไม่ได้** server ตอบ `DATA_RESET` ใบใหม่ยังบันทึกได้ตามปกติ
- ชื่อคีย์ localStorage เดิม (`mgs_quotes`, `syncQueue` …) ไม่เปลี่ยนชื่อและโครงสร้าง มีแค่คีย์ใหม่ `mgs_dataEpoch` และ `mgs_quotes_backup`

## ย้อนกลับ (ถ้าล้างผิด)
1. เปิดไฟล์ `BACKUP …` ที่ระบบสร้างไว้ → คัดลอกแท็บ Quotations ทั้งแท็บกลับไปวางทับในชีทหลัก
2. รัน `importUploadFile` ไม่ได้ในกรณีนี้ เพราะไฟล์มีสถานะอื่นปน ให้ทำด้วยมือตามข้อ 1
3. เปิด Settings แถว 2 → ในคอลัมน์ Detail แก้ค่า `"dataEpoch"` เป็นค่าใหม่อะไรก็ได้ (เช่น เติม `-R` ท้ายค่าเดิม) แล้วเพิ่ม `SettingsRev` อีก 1
   ทุกเครื่องจะล้างสำเนาแล้วโหลดชุดที่กู้คืนใหม่
